# Felhasználói Történetek (User Stories)

1. **Termékek tárolása:** Mint felhasználó, szeretnék elektronikai (`ElectronicProduct`) és élelmiszer (`FoodProduct`) termékeket felvenni a katalógusba.
2. **Rendezés:** Mint felhasználó, szeretném a termékeket ár szerint (`PriceSortStrategy`) vagy név szerint (`NameSortStrategy`) kilistázni.
3. **Keresés és összérték:** Mint felhasználó, szeretnék ID vagy név alapján keresni (`findProduct`), és lekérdezni a raktárkészlet összértékét.
4. **Fájlba mentés:** Mint felhasználó, szeretném, ha kilépéskor a termékek elmentődnének a `data/catalog.csv` fájlba, induláskor pedig betöltődnének onnan.
